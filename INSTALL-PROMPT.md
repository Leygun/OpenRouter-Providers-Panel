# Промпт для установки агентом

Скопируйте текст ниже целиком в чат DeepSeek Harness на нужном компьютере
(рабочая директория должна содержать распакованный каталог `dsh-openrouter-providers`).

---

Установи постоянный плагин профиля из каталога `dsh-openrouter-providers` в текущей
рабочей директории. Это пакет-плагин DeepSeek Harness, а не динамический Cordis-плагин,
поэтому определить и запускать его через `cordis_define` не нужно.

Что сделать:
0. Сначала проверь, есть ли у пользователя интерфейс DSH: если да, самый простой путь —
   **Настройки → Плагины → «Add plugin»** и адрес `https://github.com/Leygun/OpenRouter-Providers-Panel`
   (пакет объявляет `dsh.bundle`, поэтому строка композиции добавляется сама). Ручная
   установка ниже — для случая, когда интерфейса нет или установщик недоступен.
1. Прочитай `dsh-openrouter-providers/INSTALL.md` и следуй ему.
2. Определи каталог профиля: `$DSH_HOME/profiles/web` (по умолчанию `~/.dsh/profiles/web`).
   Пакет должен оказаться в `<профиль>/node_modules/dsh-openrouter-providers/`.
3. Скопируй каталог туда. Перед правкой `cordis.patch.yml` сделай его копию
   (`cordis.patch.yml.orig`) и добавь в конец списка строку:

   ```yaml
   - insert:
       - id: openrouter-providers
         name: dsh-openrouter-providers
   ```

   Если файл содержит пустой массив `[]` — замени его этой строкой.
4. Если файловая песочница заблокирует запись в `~/.dsh` (это вне рабочей директории),
   запроси расширение доступа у пользователя и повтори ту же команду — не обходи блокировку
   другими путями.
5. Проверь результат:
   - `node --check <профиль>/node_modules/dsh-openrouter-providers/lib/client.js` и `.../lib/index.js`;
   - `dsh --profile web --dump-config | grep -A2 openrouter-providers` — строка должна быть в композиции.
6. Скажи пользователю, что нужно перезапустить `dsh web` и обновить страницу, после чего
   раздел появится в **Настройки → «Провайдеры OpenRouter»**. Management API key
   вводится в панели отдельно и на каждой машине свой.

Ничего не меняй ни в одном поставляемом (shipped) пресете и не редактируй файлы в
установочном каталоге DSH — только каталог профиля пользователя.
